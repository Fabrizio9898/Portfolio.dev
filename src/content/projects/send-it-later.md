## El problema

WhatsApp Web no permite programar mensajes: si querés saludar a alguien a las 9 de la mañana, tenés que estar ahí a las 9.

## La solución

Una extensión de Chrome donde escribís el mensaje, elegís contacto, día y hora, y se envía sola mientras WhatsApp Web esté abierto.

## Lo técnico

- Extensión con interfaz en React.
- Programación de envíos persistida en el navegador.
- Publicada en la Chrome Web Store.

<div data-lang="en">

## The problem

WhatsApp Web can't schedule messages: if you want to greet someone at 9 am, you have to be there at 9.

## The solution

A Chrome extension where you write the message, pick the contact, day and time, and it sends itself as long as WhatsApp Web is open.

## Under the hood

- Extension UI built with React.
- Scheduled sends persisted in the browser.
- Published on the Chrome Web Store.
